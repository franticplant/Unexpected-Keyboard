# v2.1.0-fork.1

First release of the fork, based on Unexpected Keyboard 2.1.0.

## Highlights

- **Macros and snippets.** Type a trigger such as `;sig` and press space,
  enter or tab. Entries can be restricted to specific apps and can insert text
  with date/time/clipboard variables or run a key sequence such as `ctrl,a`.
- **In-app editor.** Settings → Macros & snippets. The editor validates the
  JSON before saving and ships with examples.
- **Privacy.** Snippets are disabled in password fields. The configuration
  stays in app-private storage and never leaves the device.

## Upgrade notes

- The application id is unchanged (`juloo.keyboard2`). A debug build uses
  `juloo.keyboard2.debug` and installs alongside upstream.
- The fork has its own release key. It cannot update the upstream app in place.
- `versionCode` jumps to 2010001 to stay above upstream's version code.

## Known issues

- No macro picker yet; macros are invoked by typing a trigger.
- Clipboard images and personal autocorrect are designed but not implemented
  in this release.
- The macro editor is raw JSON; per-app profiles are edited in the file rather
  than through a dedicated UI.
